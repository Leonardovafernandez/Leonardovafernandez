## 👨‍💻 Sobre mim

Sou profissional de dados com experiência em administração de bancos de dados, análise de dados, consultas SQL, modelagem e otimização de processos.

Ao longo da minha trajetória, venho aprofundando meus conhecimentos em Analytics e Engenharia de Dados, conectando minha experiência com bancos de dados à construção de pipelines, processos de ETL/ELT e soluções para integração, transformação e disponibilização de dados.

Acredito que bons resultados começam com dados confiáveis, processos bem estruturados e uma arquitetura capaz de transformar informações em valor para o negócio.

Atualmente, meus principais interesses são:

* 🏗️ **Engenharia e Arquitetura de Dados:** construção de pipelines, Data Warehouses e processos de integração.
* 📊 **Analytics e Business Intelligence:** exploração de dados, indicadores e suporte à tomada de decisão.
* 🐍 **Automação com Python e SQL:** desenvolvimento de processos para reduzir tarefas manuais e aumentar a eficiência.
* 🗄️ **Bancos de Dados:** modelagem, otimização de consultas e desempenho em ambientes Oracle e PostgreSQL.
* ☁️ **Cloud e Big Data:** aprendizado e experimentação com tecnologias para processamento e armazenamento de dados.
* 🤖 **Dados e Inteligência Artificial:** exploração de aplicações de IA para automação, análise e qualidade de dados.

## 🚀 Projetos e estudos práticos

Utilizo este espaço para desenvolver projetos, experimentar tecnologias e consolidar conhecimentos em dados e desenvolvimento de software.

### 🏗️ Data Warehouse com Python, PostgreSQL e Airflow

Projeto de Engenharia de Dados voltado à construção de um fluxo automatizado de ingestão, transformação e organização de dados.

**Principais conceitos e tecnologias:**

* Python para processamento e transformação.
* PostgreSQL para armazenamento.
* Apache Airflow para orquestração.
* Docker para configuração do ambiente.
* Arquitetura em camadas Bronze, Prata e Ouro.
* Organização de pipelines e separação de responsabilidades.

### 🌊 Data Lake e processamento de dados

Estudos práticos sobre construção de arquiteturas para armazenamento e processamento de dados, explorando diferentes tecnologias e padrões de organização.

**Tópicos explorados:**

* Arquivos CSV e Parquet.
* Data Lakes e Data Warehouses.
* Processamento e transformação de dados.
* Apache Spark e MinIO.
* Integração entre bancos de dados e ferramentas de processamento.

### 📊 Analytics e qualidade de dados

Exploração de técnicas para transformar dados brutos em informações confiáveis e úteis para análises.

**Principais tópicos:**

* Consultas SQL para análise e validação.
* Modelagem de dados para relatórios.
* Comparação e validação entre camadas de dados.
* Construção de indicadores.
* Automação de verificações e identificação de inconsistências.
